# Contributing to DevOpsLesson

Thanks for helping improve **DevOpsLesson**! This repository is a curated index of the free tutorials, playgrounds, roadmaps, and cheatsheets on [devopslesson.com](https://devopslesson.com). Contributions that fix, improve, or extend these resources are very welcome.

## Ways to contribute

- 🐛 **Report a broken link or typo** — open an [issue](../../issues/new/choose).
- ✨ **Suggest a resource** — a tutorial, playground, or guide that fits the learning path.
- 📝 **Improve the README** — clearer wording, better structure, fixed formatting.

## How to submit a change

1. **Fork** this repository.
2. **Create a branch** off `main`:
   ```bash
   git checkout -b fix/broken-docker-link
   ```
3. **Make your change** and commit with a clear message:
   ```bash
   git commit -m "Fix broken Docker tutorial link"
   ```
4. **Push** your branch and **open a Pull Request** against `main`.
5. Fill out the PR template and link any related issue.

> ⛔ Direct pushes to `main` are disabled. All changes go through a Pull Request and review.

## Guidelines

- Keep links **relevant** to DevOps learning (Docker, Kubernetes, Terraform, CI/CD, AWS, Git, Linux, SRE, cloud).
- Use **descriptive link text** (e.g., `Kubernetes Tutorial`, not `click here`).
- One logical change per Pull Request.
- Make sure all links **work** and use `https://`.
- Match the existing Markdown style and formatting.

## Code of Conduct

By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for contributing! ⭐

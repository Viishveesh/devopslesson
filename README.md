## What is DevOpsLesson?

**DevOpsLesson is a free online platform that teaches DevOps hands-on.** Instead of watching videos, you type real commands in interactive browser labs that check your work step by step. It covers the full DevOps toolchain — **Docker, Kubernetes, Terraform, CI/CD, AWS, Git, and Linux** — through structured tutorials, career roadmaps, and printable cheatsheets. Everything is 100% free and requires no account.

This repository is a **curated index** of everything on DevOpsLesson, so you can navigate the whole learning path from one place.

## Frequently Asked Questions

**What is DevOps?**
DevOps is a set of practices that combines software development (Dev) and IT operations (Ops) to shorten the delivery lifecycle and ship reliable software faster through automation, CI/CD, and infrastructure as code. Start with [What is DevOps?](https://devopslesson.com/what-is-devops)

**Is DevOpsLesson free?**
Yes. Every tutorial, playground, roadmap, and cheatsheet is completely free, and no account is required.

**How do I start learning DevOps?**
Follow the [DevOps Engineer Roadmap](https://devopslesson.com/roadmaps/devops-engineer): Linux basics → Git → Docker → CI/CD → Kubernetes → Terraform → Cloud.

**Can I practice DevOps hands-on in the browser?**
Yes. The [interactive playgrounds](https://devopslesson.com/playground) let you type real Docker, Kubernetes, Terraform, and Linux commands in a simulated terminal that checks your work — no install or signup.

**Which tools does DevOpsLesson cover?**
Docker, Kubernetes, Terraform, CI/CD (GitLab & GitHub Actions), AWS, Git, and Linux, with more added regularly.

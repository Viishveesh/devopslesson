# Security Policy

This repository is a curated index of links to [devopslesson.com](https://devopslesson.com). It contains no executable code, so security risk is minimal.

## Reporting a concern

If you find a malicious, hijacked, or unsafe link in this repository, or a
security issue on the DevOpsLesson website, please report it privately:

- 📬 Email: **contact@devopslesson.com**
- 🔒 Or use GitHub's [private vulnerability reporting](../../security/advisories/new)

Please **do not** open a public issue for security concerns. We aim to respond
within 72 hours.

## Supported

The `main` branch is the only actively maintained version.
